# 项目状态

更新时间：2026-09-22

## 第一阶段已完成

- MySQL 数据源的新增、编辑、删除、测试连接、表与字段元数据读取。
- MySQL 到 MySQL 的单表整表同步任务，支持追加与清空重写。
- 确定性生成 SeaTunnel JSON，预览和持久化快照均隐藏密码。
- SeaTunnel REST 提交、状态与指标轮询、停止，以及服务重启后的活动任务恢复。
- 同一任务单活动运行保护、状态事件时间线、错误脱敏和引擎离线陈旧标记。
- Overview、数据源、任务列表、四步创建向导、任务详情和运行详情页面。
- SeaTunnel、API、Web 的本地启动/停止脚本，以及可选 MySQL 演示数据脚本。

## 已验证

- 后端单元和集成测试通过。
- API 使用默认文件型 H2 成功启动，Flyway 初始化成功。
- 系统状态、概览、数据源列表、任务列表接口完成本机 HTTP 冒烟。
- 前端类型检查、单元测试与 Next 生产构建通过。
- 使用本机浏览器检查了概览、数据源空状态和新建任务向导。

## 尚未完成真实链路验收

当前网络无法连接 Apache 下载端点，未能在本机下载 SeaTunnel 2.3.13，因此以下项目仍需在可访问官方镜像的网络中执行：

- Zeta 集群启动与 REST 端口在线检查。
- MySQL 源表到目标表的真实 APPEND / REPLACE 同步。
- 长任务停止、真实运行指标和服务重启后的 jobId 重关联。

可通过 `SEATUNNEL_DOWNLOAD_URL` 指定可信的 Apache 镜像，然后按 README 的启动步骤完成验收。

## 第一阶段边界

暂不支持 Cron、CDC、多表任务、自定义 SQL、字段改名、Upsert、增量水位、断点恢复、登录和多租户。
